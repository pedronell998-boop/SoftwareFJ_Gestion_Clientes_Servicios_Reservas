# Publicación del proyecto en GitHub

1. El integrante que tenga permiso de creación debe crear un repositorio para el grupo, por ejemplo: `SoftwareFJ_Gestion_Clientes_Servicios_Reservas`.
2. Configurar el acceso para los cinco integrantes y el tutor, según las indicaciones del curso.
3. Descomprimir el ZIP y abrir la carpeta `Fase4_SoftwareFJ` en Visual Studio Code.
4. Abrir la terminal en esa carpeta y ejecutar:

```bash
git init
git add .
git commit -m "Desarrollo inicial del Sistema Software FJ - Fase 4"
git branch -M main
git remote add origin PEGAR_URL_REAL_DEL_REPOSITORIO
git push -u origin main
```

5. Copiar la URL real del repositorio y reemplazar el campo pendiente del informe y del mensaje para el foro.
6. Cada integrante debe realizar aportes propios en el repositorio. No se deben atribuir commits o tareas a personas que no los hayan realizado.
